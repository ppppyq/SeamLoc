# Related Open-Source Projects

These resources cover local odometry, handheld acquisition, and sensor calibration. The inclusion of a project here does not imply that every listed package is a SeamLoc dependency or an experimental baseline.

| Project | Official repository | Role |
| --- | --- | --- |
| FAST-LIVO2 | https://github.com/hku-mars/FAST-LIVO2 | Adopted LIVO estimation and mapping backbone |
| FAST-LIO | https://github.com/hku-mars/FAST_LIO | Related LiDAR-inertial odometry work |
| LIV_handhold | https://github.com/xuankuzcr/LIV_handhold | Reference handheld hardware and sensor synchronization resources |
| FAST-Calib | https://github.com/hku-mars/FAST-Calib | Related LiDAR-camera calibration toolkit |

Please consult each upstream repository for its current documentation, citations, and license. When maintaining this list, also update the related-project entries in `README.md` and `docs/index.html`.
